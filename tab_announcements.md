# Announcements

## DockSec is now an OWASP Lab Project!

We are thrilled to announce that DockSec has been officially accepted as an OWASP Lab Project. This milestone marks a significant step in our mission to make container security accessible and actionable for developers worldwide.

### Recent Updates

- **v2026.8.19 Released**: Commit your scan policy to the repository with a `.docksec.yml`
  configuration file - severity thresholds, CI gates, report formats, and disabled rules
  now live alongside your Dockerfiles instead of in per-developer flags. Includes a
  published JSON Schema for editor autocomplete and validation.
- **v2026.7.5 Released**: Full support for multi-LLM analysis and professional reporting.
- **29,000+ Downloads**: Growing community of security-conscious developers.
- **New Documentation**: Updated guides for CI/CD integration.

Stay tuned for more updates as we continue to evolve DockSec!
